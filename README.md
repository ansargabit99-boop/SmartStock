# SmartStock

Умная закупка для магазина: загружаете продажи (CSV, Excel, PDF, Word, фото или текст), получаете план закупки на неделю, тренды, идеи новых товаров и проверку акций поставщика.

## Запуск
Откройте `index.html` в браузере (двойной клик). Сборка и сервер не нужны.

## Что работает без Claude
- Загрузка CSV / Excel / JSON / PDF с текстом / Word (библиотеки подгружаются с cdnjs, нужен интернет)
- Расчёт плана закупки, сезонность, тренды, проверка акций, просьбы покупателей
- Разбор «грязного» текста простым парсером

## Что работает только когда страница открыта в Claude (claude.ai артефакт)
- Вопросы к ИИ-помощнику и идеи новых товаров
- Чтение фото тетради/накладной и сканов PDF
- Умный разбор «грязного» текста

Эти функции используют `claude.use('sample')` из среды артефактов Claude. Чтобы они работали вне Claude, замените вызовы `sample(...)` в `index.html` на запрос к Claude API через ваш собственный сервер (ключ API нельзя хранить в браузере).

## Как считается заказ
Среднее продаж за 4 недели x коэффициент сезона + 10% запаса - остаток.
